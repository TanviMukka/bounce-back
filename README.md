# Franklin, Bounce Back!
A small game in godot where a fox-human called Franklin has to jump on emerald platforms while deciding the answer for some interesting life choices. Will Franklin pick the right choice and bounce back (we hope he does) or will he fail this challenge?

A game built by Tanvi, Hamsadhwani, and Fiona during Hack Club's Haven Columbus Hackathon.

### Live Demo Link
[View Live Project](https://shadow-d321.itch.io/franklin-bounce-back)

### Features
- A fox named Franklin, who was wonderfully designed by Fiona and Hamsadhwani.
- Emerald platforms built by Tanvi on which Franklin jumps to make it through the challenge.
- Five questions with two options each which extremely challenge Franklin.

### How to play
Keep walking to the right (forward) and jump when a platform ends to land on the next one. When a question pops up, select your answer by either clicking 1 or 2 on your keyboard. If you select the wrong answer, you get moved to the beginning of the game. If you get it right, you advance.
